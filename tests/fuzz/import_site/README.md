# Fuzz corpus: `tools/import_site.py`

Site files the importer must refuse, each with a reason and without writing anything
(M7.5 spec claim 16). Every file is derived from the shipped `m4_test_building` with one
thing wrong, named by its file name. The oversized case is generated by the test rather
than committed. `tools/tests/test_import_site.py` runs them all, plus random mutations of
a good file.
