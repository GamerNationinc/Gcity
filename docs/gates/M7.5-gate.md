## 3. Demo script

Steps 1–5 on any Linux x86_64 machine with Rust; the rest on the Deck. The Steam shortcut
runs `build/linux/gcity.x86_64` with its launch options (`-- <flags>`); the export was
rebuilt from this branch.

1. `tools/test.sh` (from `bash -l`, so `cargo` is on the path) → `547 tests, … 0
   failed`, twenty-four `ok` replay lines, `all stages passed`.
2. `$(tools/godot.sh) --headless --path . -s tools/make_m6_fixtures.gd` → the four runs
   re-authored at human scale; `m6-stealth: detected 0, alarms 0, bodies 0, traces 0`.
3. `$(tools/godot.sh) --headless --path . -s tests/run_tests.gd -- res://tests/world/test_site_system.gd::test_the_warehouse_door_is_offered_to_a_squad_as_an_entry`
   → passes: the Q4 door, three faces of content, offered to a squad (item 28).
4. A save from before: in a written save set `"save_schema_version": 2` and load it (F9)
   → refused, "from before human scale (M7.5)… this build reads version 3".
5. `python3 tools/import_site.py tests/fuzz/import_site/two_pieces_one_slot.json x` →
   refused with the slot named, nothing written.
6. Launch `-- --mission --demo`. → Through the gate, down the road, round the lot, up the
   two-cell step, the grate, the 2 m tunnel, the hack, out: `run scored: seen 0, alarms 0,
   bodies 0, traces 0` (it plays the fixtures' world, item 26). A person, 1.8 m, under
   2 m doors in 3 m rooms.
7. Launch `-- --wilds`. → Out through the gate on foot; the road climbs and drops a level
   at a time and the capsule fits under every tunnel.
8. Launch `-- --create`. → Cold Storage's empty lot. D-pad moves the yellow cursor, R1/L1
   a level, Y the next piece, A places, B removes, X turns. Build anything, put a guard
   post (end of the palette) inside it, View → "Save this site". The run log names the
   file under `~/.local/share/godot/app_userdata/Gcity/sites/` (and `autosave.json` there
   every 15 s while the lot changes). View → "Open" it again:
   it comes back as you left it.
9. On a desktop: `python3 tools/import_site.py <that file> my_site "My site"` → written to
   `content/site/my_site.json`, clean under `tools/validate_content.py`.
