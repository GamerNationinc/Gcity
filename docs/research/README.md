# Research notes

One short note per source, and what was taken from it (standards §9.3). A note here
without a corresponding spike (`docs/specs/spike-*.md`) or ADR is reading, not
research: worth doing, not progress at a gate.

## Note format

```
# <source title>
Type:     paper | talk | postmortem | book | code
Link:     <url or citation>
Topic:    navigation | utility AI | determinism | data-oriented design | formal methods | postmortem
Taken:    the one or two ideas that changed a decision here, and where (ADR-00N / spike name)
Rejected: what it argues that we are not doing, and why
```
